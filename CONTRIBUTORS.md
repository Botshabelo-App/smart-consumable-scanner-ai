## How to contribute

The project is currently in **Maintenance Mode** while RC1 pilots are evaluated. Contributions are limited to:

- Bug fixes and stability improvements.
- Security patches and dependency updates.
- Documentation corrections and clarifications.
- AI model improvements backed by validated datasets and evaluation reports.
- Pilot feedback-driven changes.

Please ensure any code change includes:

1. A clear description of the bug, pilot finding, or validated improvement it addresses.
2. Updated or new tests.
3. Updated documentation.
4. A note in `CHANGELOG.md`.
